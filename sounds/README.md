# Sound Effects

Add the following MP3 files to enable sound effects:

- `swipe.mp3` - Subtle whoosh sound for each swipe
- `like.mp3` - Positive tone when liking
- `match.mp3` - Celebratory sound when logging a match
- `complete.mp3` - Session/goal complete notification
- `limit.mp3` - Warning when limit is reached

## Recommended Sources

- [Freesound.org](https://freesound.org) - Free sound effects
- [Mixkit](https://mixkit.co/free-sound-effects/) - Free sound effects

## File Requirements

- Format: MP3
- Duration: 0.5-2 seconds
- Size: Under 100KB each
